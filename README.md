# CareScout

CareScout is a full-stack web application designed to help students easily find in-network healthcare providers. It features a recommender system that connects users in Illinois to the nearest hospital or care facility compatible with their insurance coverage, helping them avoid unexpected costs during emergencies.

### Prerequisites
Make sure you have **Node.js** (with npm) and **Python 3** (with pip) installed on your machine.

## Run: 
```
chmod +x ./run_carescout.sh
./run_carescout.sh
```
## Alternative instructions if the above does not work:
Backend: 
```bash
pip3 install flask-cors
python3 backend_flask.py
```
Frontend:
In a seperate terminal, 
```bash
cd frontend
npm install
npm start
```
